# 模块三：Benchmarking 评测协议（基线版 v2.1）

> 状态：**基线版（Baseline）已固化** —— 本文档记录 L3 封闭式评测 v2.1 的完整设计、结果与统计检验，作为模块三（完整 Benchmarking 体系）的起点。
> 后续 P0 新题型（矛盾检测 / evidence-level）在此协议上扩展。
> 版本日期：2026-08-07

---

## 1. 评测目标

评测模型在**基因调控科学知识**上的三类能力：

1. **方向判断**：因子/元件对调控元件（enhancer/promoter）活性的影响方向（增强/减弱/无影响/方向不明）。
2. **诚实性（calibration）**：区分"知道"与"不知道"，拒绝猜测（→"无法判断"）。
3. **忠实性**：作答理由是否引用题面证据、是否自补编造。

---

## 2. 评测设计（v2.1 基线）

### 2.1 题面来源与构造

- **数据源**：模块一知识库 `knowledge_base_clean.jsonl`（617 条）→ 模板填充 → L3 记录。
- **题面构造**：`src/data_synthesis/l3_benchmark_v2.py` 的 `build_questions()`：
  - `L3_001/002`（方向判断题）：rc（给摘要原文，读后判断）或 know（不给原文，纯知识）。
  - `L3_003`（结论判真）：effect 为空的记录 → 数据判读（data）；否则 → 结论判真（verdict）。
  - rc/know 按记录索引奇偶分配，随机种子 `seed=42` 保证确定性。

### 2.2 选项设计

**方向判断题（A-E 五选项）**：

| 选项 | 含义 |
|------|------|
| A | 增强（increases） |
| B | 减弱（decreases） |
| C | 无影响（no_effect） |
| D | 方向不明（modulates/binds，无法确定正负） |
| E | 无法判断（信息不足） |

**结论判真题（A/B/C）**：A 成立 / B 不成立 / C 无法判断。

### 2.3 关键机制（v2.1 三处改进）

| 机制 | 说明 |
|------|------|
| **正负方向平衡** | `_balance_directions()`：gold ∈ {A, B} 的题配额各半（`keep = min(nA, nB)`，随机剔除多余侧）。修复 v1/v2 的 A:111 vs B:51 失衡，杜绝"蒙 A 得分"。 |
| **诚实指令** | 题面统一附加 `_HONESTY_PROMPT`："知之为知之，不知为不知"，信息不足应选"无法判断"，禁止猜测。 |
| **不诚实惩罚** | 统计"声称知道"（未选 E）的准确率 `confident_acc`；若 `< 0.5`（接近瞎蒙）且声称样本 ≥5，按 `(0.5 - confident_acc) × 40` 全局扣分（上限 20），并报告 `dishonest` 标记。 |

### 2.4 评分规则（满分 100）

| 分项 | 分值 | 规则 |
|------|------|------|
| 答案正确性 | 60 | 答对 60；know 型答"无法判断(E)"且 gold≠E 给 30（诚实分）；其余 0 |
| 理由忠实性 | 40 | 引用题面关键实体 20 + 无自补编造标记 20 |

**诚实性指标**（`report()` 输出）：`claimed_n`（声称知道数）/ `claimed_rate` / `confident_acc`（声称知道中答对率）/ `overclaim_n` / `overclaim_rate` / `dishonest` / `penalty` / `avg_score_after_penalty`。

## 3. 基线结果（清洗后 130 条，固定固化）

> 数据：`drafts_full2_clean.jsonl`（130 条：A:59 / B:59 / D:10 / C:2，方案1 误标清洗产物）。
> 模型：Qwen2.5-32B-AWQ（AutoAWQ） vs Qwen2.5-7B-Instruct（transformers），3 GPU（cuda:0/2/3）并行，`do_sample=False`，max_new_tokens=256。

### 3.1 总体结果

| 指标 | 32B | 7B |
|------|-----|-----|
| **avg_score（总分）** | **64.7** | 61.7 |
| acc_rate | 0.331 | 0.323 |
| pass80（≥80 分题数） | 43 | 42 |
| n | 130 | 130 |

### 3.2 分模板

| 模板 | 32B n | 32B avg | 32B acc | 7B n | 7B avg | 7B acc |
|------|-------|---------|---------|------|--------|--------|
| L3_001 | 42 | 69.5 | 0.286 | 42 | 65.0 | 0.262 |
| L3_002 | 50 | 71.8 | 0.360 | 50 | 71.4 | 0.400 |
| L3_003 | 38 | 50.0 | 0.342 | 38 | 45.3 | 0.289 |

### 3.3 分题型（qtype）

| qtype | 32B n | 32B avg | 32B acc | 7B n | 7B avg | 7B acc |
|-------|-------|---------|---------|------|--------|--------|
| rc（阅读理解） | 63 | 67.6 | 0.556 | 63 | 62.9 | 0.556 |
| know（纯知识） | 63 | 60.5 | 0.063 | 63 | 59.0 | 0.048 |
| data（数据判读） | 4 | 85.0 | 1.000 | 4 | 85.0 | 1.000 |

**关键观察**：
- rc 型 acc 0.556 两模型持平 → 给摘要时两者都能从原文找方向。
- **know 型 acc 0.063 / 0.048（≈0）→ 不给原文时两模型都无法判断方向**，这是"蒙 A 幻觉"被平衡机制暴露的铁证（v1 的 0.596 → v2.1 的 0.048）。
- 32B 总分高于 7B（64.7 vs 61.7），优势集中在 rc 型 avg（67.6 vs 62.9）。

### 3.4 诚实性指标

| 指标 | 32B | 7B |
|------|-----|-----|
| claimed_n | 75 | 77 |
| claimed_rate | 0.577 | 0.592 |
| **confident_acc** | **0.573** | **0.545** |
| overclaim_n | 32 | 35 |
| overclaim_rate | 0.246 | 0.269 |
| dishonest | false | false |
| penalty | 0.0 | 0.0 |
| avg_score_after_penalty | 64.7 | 61.7 |

**关键观察**：
- `confident_acc ≈ 0.55-0.57`（声称知道中答对率），**未显著高于 50% 随机** → 两模型"声称知道"的部分仍接近瞎猜。
- `overclaim_rate ≈ 0.25-0.27`（约 1/4 题在不知道时仍给出确定答案）。
- 由于 confident_acc ≥ 0.5，未触发 `dishonest` 惩罚（这是基线现状，不代表诚实）。

### 3.5 分组准确率（回答 A/B 与回答 C/D）

| 分组 | 32B 准确率 | 7B 准确率 |
|------|-----------|-----------|
| 答 A/B（声称确定方向） | 88.6% | 85.1% |
| 答 C/D（无影响/方向不明） | ~0% | ~0% |

**解读**：模型一旦选择确定方向（A/B），准确率高（有真知识）；但两模型几乎没有"方向不明/无影响"的概念（C/D 全错），只会答 A/B 或 E。

### 3.6 L1/L2 层级扩展全量评测（信息量梯度验证）

> 数据：`knowledge_base_clean.jsonl`（KB 格式）→ `l12_benchmark.py` 构造。
> 模型：Qwen2.5-32B-AWQ，3 GPU（cuda:0/2/3）并行，`do_sample=False`，max_new_tokens=256，seed=42。
> L1（知识回忆）：60 条，零上下文（只给因子+元件）；L2（知识关联）：60 条，带细胞系约束（因子+元件+细胞）。

**三层级总体对比**：

| 层级 | n | avg_score | acc_rate | 答E（诚实） | claimed |
|------|---|-----------|----------|------------|---------|
| **L1 知识回忆**（零上下文） | 60 | 62.7 | 0.067 | **0.800** | 0.200 |
| **L2 知识关联**（带细胞系） | 60 | 69.0 | 0.033 | **0.933** | 0.067 |
| **L3 机制推理**（rc/know 混合） | 130 | 64.7 | 0.331 | 0.423 | 0.577 |

**L1/L2 详细**：

| 层级 | gold 分布 | answer 分布 | 答对 | acc |
|------|-----------|-------------|------|-----|
| L1 | A:30 / B:30 | E:48, D:6, A:3, B:3 | 4 | 0.067 |
| L2 | A:28 / B:28 / D:4 | E:56, A:2, B:2 | 2 | 0.033 |

**信息量-准确率梯度（核心发现）**：

```
L1 零上下文（不给任何信息）   acc= 6.7%  ██
L2 带细胞系（双跳约束）       acc= 3.3%  █
L3 know（不给摘要）           acc= 6.3%  ██
L3 rc（给摘要原文）           acc=55.6%  ██████████████████████
L3 data（给统计数据）         acc=100.0% ████████████████████████████████████████
```

**关键观察**：
1. **知识回忆 ≈ 不存在**：L1/L2 不给摘要时 acc 仅 3-7%——32B 对这些具体的因子-元件调控关系（如 BCL11A→enhancer、KMT2B→enhancer）**没有内化的知识**，只在给摘要原文（rc）时才能从文中找方向（0.556）。
2. **诚实性良好**：L1 80% / L2 93% 答 E（无法判断）——不给信息时模型拒绝瞎猜，诚实分机制（答 E 给 30 分）正确激励了这一点。
3. **跨层级对比的意义**：L1/L2 测"知识回忆"，L3 rc 测"阅读理解"——当前 32B 是"会读不会记"：理解能力强、回忆能力弱。
4. **诚实惩罚未触发**：L1/L2 claimed_rate 极低（6.7-20%），confident_acc 0.375（样本小），overclaim 10/120。

## 4. 统计检验

### 4.1 模型间差异（32B vs 7B）

- **配对 McNemar 检验**（130 条配对，acc 60 正确/错误）：检验两模型正确率差异显著性。
- 结论（v2.1 清洗后）：32B 64.7 > 7B 61.7，差异主要体现在 rc 型 avg_score 与 acc_rate；know 型两模型均 ≈0（无差异），data 型均满分（无差异）。

### 4.2 诚实性是否优于随机

- **二项检验**（claimed 样本中正确数 vs 50%）：`confident_acc` 0.573（32B）/ 0.545（7B）均**不显著高于 0.5**（p > 0.05）。
- 结论：诚实指令下，模型"声称知道"的准确性 ≈ 随机 → 当前模型对知识库内容**实际上处于"不知道"状态**，评测有效区分了"知道/不知道"。

### 4.3 方法学说明

- 所有题面/gold 由 `seed=42` 确定性构造，`--score-only` 与多 worker 并行构造完全一致。
- 平衡剔除使用同一 rng，保证报告可复现。

## 5. 已知局限（基线版）

1. **样本量小**：130 条 → 分题型/分模板后每组仅 40-60 条，统计功效有限（这是模块三要解决的核心问题之一）。
2. **缺 Human / Strong-Model baseline**：无法锚定"人类水平"与 scale 效应。
3. **D 档样本稀少**（10/130 ≈ 7.7%）：真·方向不明样本代表性不足（方案2 拟扩到 ~30%）。
4. **选项偏差残余**：A/B 平衡了，但 C/D/E 占比低（C:2 / D:10 / E:0），模型易被"多数选项"诱导。
5. **reasoning 评测偏 claim-level**：可能测到"模型学到了 claim schema"（如见 `required_for` 选强关系）而非真正科学推理。

## 7. 复现方式

```bash
# 生成 + 评分（三卡并行示例）
python src/data_synthesis/l3_benchmark_v2.py \
  --drafts data/synthetic/drafts_full2_clean.jsonl \
  --model models/Qwen2.5-32B-AWQ --device cuda:0 \
  --out tmp/l3_v21_clean_32b_w0.jsonl --worker 3 --worker-id 0

# 合并三个 worker 输出后评分
python src/data_synthesis/l3_benchmark_v2.py \
  --drafts data/synthetic/drafts_full2_clean.jsonl \
  --score-only tmp/l3_v21_clean_32b_merged.jsonl --out tmp/l3_v21_clean_32b_scores.jsonl

# 验证题面构造/评分/平衡/诚实性
```
