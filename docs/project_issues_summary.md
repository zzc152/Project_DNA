### 1.1 方向冲突（T2 验证发现）— ✅ 已解决

| 冲突 | 数量 | 状态 |
|------|------|------|
| DNA methylation→promoter 方向矛盾（K562 increases vs not_specified decreases） | 1 对 | ✅ 已修复（K562 改 decreases，与 L3_001_15 同源错误） |
| MYCN→promoter/enhancer 多方向共存 | 2 对（11 条） | ✅ 人工核查：非标注错误，是**靶基因依赖**（MYCN 激活 MYC 靶基因、抑制神经元分化基因同时成立）；已加 `target_gene` 维度，T2 判定升级 |

**教训**：KB 的冲突键 `(factor, element, cell_line)` 缺靶基因维度，导致生物学真实被误判为标注错误——**schema 设计缺陷**，靠升级 T2 修复。

### 1.2 非法 effect（T4）— ✅ 已解决

6 条 effect 不在规范词表：`promotes / affects_interaction / co_occurs_with / correlates / regulates_expression / disrupts`。
→ 5 条修复（映射到规范方向）+ 3 条 DELCAND 删除（共现/相关非因果，见 1.3）。

### 1.3 非因果关系混入（T4 衍生）— ✅ 已删除

3 条"共现/相关"当"因果"记录（DNA methylation→gene upregulation、chromatin accessibility→promoter methylation level、targeted activation→AML differentiation），已人工确认删除。

### 1.4 因子名噪声 — ⚠️ 部分处理

- **29 条** factor 名 >30 字符（描述性短语，如 "targeted activation of this regulatory element"）。
- 已有 `_clean_factor` 过滤（L1/L2 抽样时剔除），但 KB 本体未清洗。

### 1.5 数据覆盖不均 — ⚠️ 结构性限制

- effect 分布：increases 155 / decreases 153 / required_for 123 / modulates 29 / no_effect 2 / binds 2 / **None 150**。
- **150 条 None = MPRA 扫描数据**（`direction: enriched_in_high`，有 p_value/effect_size），**不参与出题**（`_balanced_sample` 只抽明确方向的）——不是缺失，但这类记录不可用。
- **D 档（方向不明）样本极少**：modulates 29 + no_effect 2 = 31/614（5.0%），真·方向不明代表不足。

## 3. 模块三：评测问题

### 3.1 ⚠️⚠️ 题面构造漂移（重测发现，最重要）— ❌ 未修复

`l3_benchmark_v2.py`：`qtype = "rc" if idx % 2 == 0 else "know"`——qtype 依赖**全量列表索引**。

**影响**：数据增删 1 条 → 所有后续索引奇偶翻转 → 同一 id 题 rc↔know 翻转 + rng 选项 flip 漂移。
实测：final 删 3 条后，**21 条题 rc↔know 翻转、12 条 gold 未变但 acc 翻转**。

**后果**：评测结果**不可增量对比**（130 vs 129 全量对比无效，必须同题面配对），任何数据修正在评测层面都会"污染"题面。

**修复建议**：qtype 改用 `hash(id) % 2`（确定性、与集合无关）。

### 3.2 选项偏差 — ⚠️ 部分缓解

- C/D/E 占比低（C:2 / D:10 / E:0）→ 模型易被 A/B 诱导；A/B 已平衡（各 keep=min），C/D/E 未平衡。
- D 档样本稀少（10/130 = 7.7%，方案 2 拟扩到 ~30%，未做）。
- L1/L2 无 E 类 gold（KB effect 多为明确方向）→ 选项偏差残余。

### 3.3 评测功效 — ⚠️ 结构性限制

- L3 130 条分模板后每组 40-60 条、L1/L2 各 60 条 → 统计功效低（检出 10pp 差异需 300+ 条/层级）。
- 缺 Human / Strong-model baseline（无法锚定"人类水平"）。
- 知识泄漏风险：L1/L2 测常见调控关系（MYCN/BCL11A），高分可能是"见得多"。

### 3.4 诚实性指标解读 — ⚠️ 需谨慎

- confident_acc ≈ 0.55-0.57（32B）未显著高于随机 → "声称知道"部分接近瞎猜。
- 7B 在 L1/L2 的 claimed acc = 76.5%（13/17）反而优于 32B（53.8%）——但 7B 只敢答 14% 的题（过度保守）。

## 5. 对"数据集信心"的诚实回答

**支持信心的证据**：
1. 已发现的问题全部有量化证据（T1-T5 + 人工核查），不是感觉。
2. 修复后复测全清零（T1 0 / T2 0 / T4 0），人工核查确认 MYCN 冲突是生物学真实而非错误。
3. 评测结论（会读不会记、信息量梯度）在修复前后稳定，不依赖个别标注。

**动摇信心的证据**（真实存在）：
1. **L3 约 1/4 题存在因子名/因子类型问题**（11.1% + 12.7% 有重叠），这些题"测的不是科学推理"。
2. **题面构造漂移**让所有历史评测结果无法与未来严格对比。
3. T5 显示 gold 与摘要一致率仅 57.1%——即使修复后，**"摘要信息不足仍标方向"的题有 20%**，属标注哲学的缺陷（评测想要方向，但文献常常只给关联）。

**建议的下一步（按优先级）**：
1. **修评测脚本 qtype 哈希化**（1 小时，解锁增量对比）。
2. **因子名清洗**：21 条 factor_valid=false 替换为可考实体或删除（解决 11.1%）。
3. **新增验证维度 T6：因子类型校验**（修饰标记/短语/多实体当因子 → 自动识别 12.7%）。
4. **方向标注哲学**：摘要信息不足的题 gold 改 E 或标"过度自信"，解决 T5 20%。
5. （远期）方案 2 D 档扩样、Human baseline。
